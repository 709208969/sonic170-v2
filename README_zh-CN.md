# 🎹 CC01 — 键盘灯光编辑工具

> 🔧 本仓库为 **kindlestar** 为客制化键盘 **CC01**（75% 配列，热插拔 + 焊接双版）定制的配套网页工具。
> 📌 本工具由 sonic170 v2 网页（v47.79）深度适配而来：CC01 灯区 = LED0 Caps + LED1 上电指示 + 左右灯条 58 灯（LED2-59）。

## ✨ 功能特性（v1.2）

- 🎨 **每图案独立配置** — 8 图案槽（3 出厂 + 5 自定义，58 灯位图）各自保存灯效/颜色/亮度/速度
- 🖌️ **后部灯带图案编辑器** — 58 灯按 **左 29 一行 + 右 29 一行（2×29）** 显示（行0=右段/行1=左段，与键盘俯视一致），支持 橡皮/填充/反色/清空/Mirror H（段内镜像）/Mirror V（左右段交换）/Rotate 180°（整链镜像）/左右平移/方向开关
- 🎞️ **帧动画**（58 灯条，单动画槽 = 图案 3，20 帧上限×174B）— 画笔/橡皮/油漆桶/取色/选择/洋葱皮/镜像/平移/预览、5/10/30/60 fps 档位（30/60 档帧数自动封顶 20）、PNG/GIF 导入、PNG/雪碧图/GIF 导出、库与文件、上传到键盘/从键盘读回/清除动画
- 💡 **电源灯(LED1) / CapsLock 灯(LED0) / 后部灯带(LED2-59) 独立控制**（亮度上限 200，与固件一致）
- 🔥 **网页内置 DFU 烧录**（已适配 CC01 STM32F072：128KB = 64 页 × 2KB 逐页擦除）
- 🌐 中英双语界面 + 配置导入导出 + 固件下载（内嵌 cc01_hs v1.2.46）
- ⏫ **检查更新**（仓库可配置——首次点击会询问 owner/repo，发布时可在代码内设默认值）

### 与 sonic170 版的差异

| 项 | 处理 |
|---|---|
| 打字反馈灯效 | **产品无此功能** — UI/模式项已移除（sonic 的模式 30 Flicker/31 Caps 项已去） |
| 灯数/布局 | 13×13(169) → **后部灯带 58 灯（2×29 双行视图）** |
| 方向/变换 | 按 58 链语义重定义：Direction=整链反转、MirrorH=段内镜像、MirrorV=段交换、Rotate=180° 整链镜像；**90° 旋转与上/下移在单链灯带物理上不存在 → 按钮保留可见但禁用并带说明**（避免假操作） |
| 动画 | 帧 = 58 灯 RGB（174B）、槽 = 图案 3 单槽、帧数上限 20（30/60fps 档自动封顶 20，档位值仍作为播放速率上传） |
| DFU | 擦除逻辑已切 F072（64 页 × 2KB） |
| 检查更新 | repo 首次点击询问配置（localStorage `cc01_gh_repo`）；资产名规则按 CC01_hs/CC01_sd |
| 固件下载 | 内嵌 cc01_hs v1.2.47；solder(cc01_sd) 按钮 disabled（正式版双板发布时启用） |
| VIA JSON 下载 | 内嵌 CC01_hs_via.json（0x4351:0x0080） |

> ⚠️ **固件配套版本 = v1.2.47**（板内持久化 + 分区渲染）：网页图案/灯效/动画/总开关全部经 value_id 1-46 写入固件 rgb_control 分区渲染系统（Caps/电源灯/后部灯带），上电 2s 开机灯效后进入分区渲染；**EEPROM 已实现板内记录（custom 驱动 cc01_eeprom.c，F0 双字编程）——网页设置关机重启保持**（总开关 OFF 按 B 计划不持久：宁开不灭）。

## 🚀 快速开始

1. 📂 用 **Chrome 或 Edge** 打开 `cc01-rgb-control.html`（双击即可，完全离线）。
2. 🔌 点击**连接**，选择键盘（0x4351:0x0080）。
3. 🎚️ 编辑灯效/图案 — 连接后改动实时生效（未连接也可本地预览）。
4. ⚡ 烧录固件：拔下 USB 按住 **Esc**（bootmagic）进 DFU，用 dfu-util：
   `dfu-util -d 0483:df11 -a 0 -s 0x08000000:leave -D CC01_hs_v1.2.45.bin`

> ⚠️ **重要**：当前固件 v1.2.45 为"bitbang + 原生彩虹 + LED0/1 指示"验证版（分区渲染/图案引擎暂停中），
> 网页的图案/分区灯效控制需配合**正式版固件**（恢复 rgb_control 分区系统后）才能作用于键盘灯效；
> 在验证版固件上连接可正常读取配置但灯效控制会被固件原生渲染接管（预期行为）。
